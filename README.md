# Мои контакты

Android-приложение (Kotlin) для работы с контактами: просмотр, поиск, добавление, правка, удаление,
объединение дубликатов, импорт/экспорт VCF и CSV.

APK собирается автоматически: GitHub → Actions → «Build APK» → артефакт `moi-kontakty-apk`.

## Возможности
- Перенос контактов между аккаунтами (в т.ч. Google через системный провайдер) с проверкой копий; удаление из источника только после полного подтверждения.
- ChatGPT: вводится собственный API-ключ OpenAI (хранится только на устройстве); данные контактов отправляются только по явной галочке.
