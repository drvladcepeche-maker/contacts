# Мои контакты

Android-приложение (Kotlin) для работы с контактами: просмотр, поиск, добавление, правка, удаление,
объединение дубликатов, импорт/экспорт VCF и CSV.

APK собирается автоматически: GitHub → Actions → «Build APK» → артефакт `moi-kontakty-apk`.

## Возможности
- Перенос контактов между аккаунтами (в т.ч. Google через системный провайдер) с проверкой копий; удаление из источника только после полного подтверждения.
- ChatGPT: вводится собственный API-ключ OpenAI (хранится только на устройстве); данные контактов отправляются только по явной галочке.
- Claude: то же самое через собственный API-ключ Anthropic (выбор «ChatGPT / Claude» в диалоге ИИ-помощника): вопросы по контактам и предложение правок с подтверждением. Ключ хранится только на устройстве.
- «Связь с Claude»: тот же мост с сервером, плюс копирование адреса MCP для подключения коннектора в Claude.

- «Аккаунты синхронизации»: отдельно управляет участием аккаунта, чтением и записью для моста ChatGPT/Claude. Изменение и удаление через мост ограничены выбранным разрешённым аккаунтом. Если агрегированный Android-контакт содержит записи из отключённого для чтения аккаунта, весь такой контакт исключается из передачи, чтобы не раскрывать поля отключённого источника.

## Постоянная подпись APK

Чтобы Android мог обновлять приложение поверх предыдущей версии, все сборки должны иметь одну и ту же подпись. Один раз на доверенном Windows-компьютере запустите `tools\setup-android-signing.bat`. Скрипт создаст закрытый PKCS12-ключ и файл Base64.

В GitHub откройте **Settings → Secrets and variables → Actions** и добавьте:
- `ANDROID_KEYSTORE_BASE64` — всё содержимое `mycontacts-signing-base64.txt`;
- `ANDROID_KEYSTORE_PASSWORD` — пароль хранилища;
- `ANDROID_KEY_ALIAS` — `mycontacts`;
- `ANDROID_KEY_PASSWORD` — пароль ключа (скрипт предлагает использовать тот же пароль).

Файлы `mycontacts-signing.p12` и `mycontacts-signing-base64.txt` нельзя добавлять в Git, отправлять в чат или публиковать. Сохраните резервную копию ключа и пароля. Пока секреты не настроены, GitHub Actions использует временную debug-подпись, с которой обновление поверх APK, подписанного другим ключом, может не установиться.
